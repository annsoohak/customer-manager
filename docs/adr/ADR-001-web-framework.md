# ADR-001: 웹 프레임워크로 FastAPI를 선택

## 상태

채택

## 맥락

Customer Manager 서비스에는 비동기 처리가 가능한 웹 프레임워크가 필요하다. OpenAPI 기반의 API 문서가 자동으로 생성되어야 하며, 타입 힌트를 활용해 요청과 응답을 명확하게 정의하고 검증할 수 있어야 한다. 팀의 주 개발 언어는 Python이다.

## 결정

웹 프레임워크로 FastAPI를 사용한다.

## 대안

- Flask: 가볍고 익숙하지만 API 문서화와 데이터 검증 체계를 별도로 구성해야 한다.
- Django: 완성도 높은 기능을 제공하지만 현재 서비스의 API 중심 요구사항에는 기능과 구조가 과하다.

## 결과

적은 코드로 요청·응답 검증과 OpenAPI 문서화를 자동화할 수 있다. FastAPI와 관련 생태계에 대한 러닝 커브는 감수한다.
